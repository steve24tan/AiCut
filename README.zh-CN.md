# 逐段 · Shot Workbench

[English](README.md) | 简体中文

本地运行的分段素材与修改工作台，初始版本 `0.1.0`。

每个片段保存下一版 Prompt 草稿、修改要求、状态，以及带有历史文字快照的视频／图片版本。可以先写文字片段，再导入素材。通过「复制本段修改请求」把上下文交给现有 AI 订阅工具；本应用不调用 AI、不消耗订阅额度、不上传数据。

## 启动

需要 **Node.js 24 或更新版本**。当前电脑已验证 Node 24.20.0；没有 npm 依赖，不需要 `npm install`、Docker 或 API Key。

1. 双击项目目录的 `start.cmd`，保持终端开启。
2. 用 Chrome／Edge 打开 `http://127.0.0.1:4317`。
3. 创建项目 → 添加片段 → 填写 Prompt 和修改要求 → 复制本段修改请求。
4. 外部生成完成后点「导入新版」。也可以直接点「导入素材」，多个文件分别建立片段。
5. 等待顶部显示「所有修改已保存到本地」。关闭服务时在终端按 Ctrl+C。

或在项目目录的 PowerShell 中运行：

```powershell
npm.cmd start
```

应用只监听 `127.0.0.1`，不绑定局域网网卡。浏览器素材请求中出现的「导入／上传」仅表示从本机浏览器复制到本机素材目录。

## 保存与版本规则

- 输入停止约 650 毫秒后自动保存草稿。保存失败会提示，页面保留当前内容；离开页面会提示未保存修改。
- 「导入新版」复制原始素材，保存当前 Prompt／修改要求为只读快照，并把新版本设为采用版。
- 「存快照」建立不带素材的文字版本；新快照会成为采用版，原有素材版仍可选回。
- 「采用版本」切换预览；不覆盖正在编辑的下一版草稿。「查看快照」可查看所选版本当时的文字。
- 每个片段的 `revision` 用于阻止旧页面覆盖新修改。如果多标签页冲突，先复制未保存文字，再刷新。
- 「导出修改清单」输出所有片段的 Markdown 文字，**不是完整项目备份**。
- 导入进行中暂停编辑。批量导入按文件逐个提交；中途失败时，已完成的素材继续保留，失败片段可重新导入。

## 数据与备份

```text
ShotWorkbench/
  data/
    workbench.sqlite       项目、片段、草稿、历史快照、素材索引
    workbench.sqlite-wal   SQLite 运行时文件，可能存在
    workbench.sqlite-shm   SQLite 运行时文件，可能存在
    media/                 UUID 命名的原始素材副本
  backups/
    <timestamp>/           完整备份：数据库快照 + media/
```

运行中可以生成一致的数据库备份，然后复制只增不改的素材目录：

```powershell
npm.cmd run backup
```

只有命令输出 `Backup complete` 的备份才可用于恢复。数据库先快照、素材后复制；备份过程中新增的未引用素材可能被一起复制，不影响恢复。当前没有删除素材功能，此备份顺序依赖素材不可变／不删除这一约束。

恢复到新目录，保留原数据：

1. 停止服务。
2. 将选中的完整时间戳备份目录复制为 `.\restored-data`（如果已存在，使用另一个新目录名）。
3. 在同一 PowerShell 窗口中运行以下命令。
4. 查看项目、备注、采用版本，并实际播放素材。

```powershell
$env:SHOT_DATA_DIR = Join-Path (Get-Location) 'restored-data'
npm.cmd start
```

回到默认数据目录：停止服务，再在该窗口执行 `Remove-Item Env:SHOT_DATA_DIR`，重新启动。也可以关闭这个 PowerShell 窗口，使用 `start.cmd` 启动。

## 当前范围

已实现：多项目、文字片段、素材预览、Prompt／修改要求自动保存、复制请求、只读版本快照、采用版本切换、箭头排序、状态筛选、文字清单导出、完整备份脚本。

素材格式：MP4、WebM、MOV、PNG、JPG、WebP，单个文件最大 1 GB。播放能力取决于浏览器及编码；MOV 导入成功不等于浏览器一定能播放。应用不做转码。

后续再做：整片拆镜头／裁剪、左右并排版本对比、拖动排序、修改记录时间线、文件夹监听、项目包导入。当前逐段预览通过版本选择器切换；不存在自动生成或 AI 集成。
