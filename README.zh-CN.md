# AiCut · 本地分段创作工作台

[English](README.md) | 简体中文

本地运行的分段素材与修改工作台，版本 `0.5.1`。

每个片段保存 Prompt 草稿、修改要求、状态和带历史文字快照的素材版本。可以复制请求到外部工具，也可选择本机已登录的 Claude Code／Codex CLI 推送文字修改任务。核心工作台可离线使用；CLI 作业会发送本段文字并消耗对应订阅额度，不接模型 API Key。

## 启动

需要 **Node.js 24 或更新版本**。当前电脑已验证 Node 24.20.0；没有 npm 依赖，不需要 `npm install`、Docker 或 API Key。

1. 双击项目目录的 `start.cmd`，保持终端开启。
2. 用 Chrome／Edge 打开 `http://127.0.0.1:4317`。
3. 创建项目 → 添加片段 → 填写 Prompt 和修改要求 → 复制本段修改请求。
4. 外部生成完成后点「导入新版」。也可以直接点「导入素材」，多个文件分别建立片段。
5. 等待顶部显示「所有修改已保存到本地」。关闭服务时在终端按 Ctrl+C。

或在项目目录的 PowerShell 中运行：

```powershell
npm.cmd start
```

应用只监听 `127.0.0.1`，不绑定局域网网卡。浏览器素材请求中出现的「导入／上传」仅表示从本机浏览器复制到本机素材目录。

## 保存与版本规则

### 一条视频分成多段

导入整条视频 → 点击卡片上的 **✂ 分段** → 输入段数 → **生成分段** → **保存分段**。

例如 30 秒均分 5 段，得到 0–6、6–12、12–18、18–24、24–30 秒。可以修改边界秒数，或播放到目标位置后点击「在播放位置分段」，也能移除边界。每段至少 0.1 秒，一次最多 100 段。

第一段沿用原卡片，其余段插在后面，共用原视频文件。每段继承 Prompt；第一段保留原备注，其他段的备注为空白，独立填写。原整条版本留在第一段历史中。

每段可以再细分；「调整范围」修改单段起止位置并保存为新版本，邻段不会自动跟随。默认单段循环，取消后在段尾暂停。上方导航可快速跳到指定段；复制请求和导出清单会带原文件名与时间范围。

目前只保存播放范围，不生成独立剪辑文件；浏览器预览不是帧精确裁剪。独立导出、自动镜头检测及连续拼接预览待后续实现。

升级时会在数据目录保存 `schema-v1-before-v2.sqlite` 数据库快照，然后在事务中增加时间范围字段。升级前仍建议备份完整数据及素材；旧版应用不能安全读取新版数据，不要直接降级。

### 草稿与快照

- 输入停止约 650 毫秒后自动保存草稿。保存失败会提示，页面保留当前内容；离开页面会提示未保存修改。
- 「导入新版」复制原始素材，保存当前 Prompt／修改要求为只读快照，并把新版本设为采用版。
- 「存快照」建立不带素材的文字版本；新快照会成为采用版，原有素材版仍可选回。
- 「采用版本」切换预览；不覆盖正在编辑的下一版草稿。「查看快照」可查看所选版本当时的文字。
- 每个片段的 `revision` 用于阻止旧页面覆盖新修改。如果多标签页冲突，先复制未保存文字，再刷新。
- 「导出修改清单」输出所有片段的 Markdown 文字，**不是完整项目备份**。
- 导入进行中暂停编辑。批量导入按文件逐个提交；中途失败时，已完成的素材继续保留，失败片段可重新导入。

## 数据与备份

```text
AiCut/
  data/
    workbench.sqlite       项目、片段、草稿、历史快照、素材索引
    workbench.sqlite-wal   SQLite 运行时文件，可能存在
    workbench.sqlite-shm   SQLite 运行时文件，可能存在
    media/                 UUID 命名的原始素材副本
  backups/
    <timestamp>/           完整备份：数据库快照 + media/
```

运行中可以生成一致的数据库备份，然后复制只增不改的素材目录：

```powershell
npm.cmd run backup
```

只有命令输出 `Backup complete` 的备份才可用于恢复。数据库先快照、素材后复制；备份过程中新增的未引用素材可能被一起复制，不影响恢复。当前没有删除素材功能，此备份顺序依赖素材不可变／不删除这一约束。

恢复到新目录，保留原数据：

1. 停止服务。
2. 将选中的完整时间戳备份目录复制为 `.\restored-data`（如果已存在，使用另一个新目录名）。
3. 在同一 PowerShell 窗口中运行以下命令。
4. 查看项目、备注、采用版本，并实际播放素材。

```powershell
$env:SHOT_DATA_DIR = Join-Path (Get-Location) 'restored-data'
npm.cmd start
```

回到默认数据目录：停止服务，再在该窗口执行 `Remove-Item Env:SHOT_DATA_DIR`，重新启动。也可以关闭这个 PowerShell 窗口，使用 `start.cmd` 启动。

## 当前范围

已实现：多项目、文字片段、素材预览、Prompt／修改要求自动保存、复制请求、只读版本快照、采用版本切换、箭头排序、状态筛选、文字清单导出、完整备份脚本。

素材格式：MP4、WebM、MOV、PNG、JPG、WebP，单个文件最大 1 GB。播放能力取决于浏览器及编码；MOV 导入成功不等于浏览器一定能播放。应用不做转码。

后续再做：自动镜头检测、裁剪文件导出、连续拼接预览、左右并排版本对比、拖动排序、文件夹监听和项目包导入。可选 CLI 作业只处理文字 Prompt，不生成视频。

## 验证

### 链接下载（⤓ 链接下载，v0.10）

顶部「⤓ 链接下载」：贴 YouTube／TikTok／抖音／B 站等视频页链接，选「视频 MP4 → 新片段」或「音频 MP3 → 素材库」。AiCut 不自己解析网站，而是调用这台电脑的 yt-dlp（合并 MP4、转 MP3 需要 ffmpeg）；视频优先 H.264 + AAC、最高 1080p，方便浏览器播放和导入剪映。完成后视频成为新片段（备注写上来源链接和作者），音频存入素材库（来源、作者栏位已填）。下载在后台进行，可取消，失败时显示 yt-dlp 的原因。

- 安装：`winget install yt-dlp.yt-dlp Gyan.FFmpeg`，或用 `SHOT_YTDLP_BIN` 指定 yt-dlp.exe 完整路径、`SHOT_FFMPEG_BIN` 指定 ffmpeg 目录。
- 抖音等要登录 cookie 的网站：设 `SHOT_YTDLP_COOKIES_BROWSER=firefox`（Chrome 开着时 cookie 常被锁）。
- 网站改版会让下载失效，先 `yt-dlp -U` 更新。下载别人的内容请自行确认版权与平台条款。

### 2.5D 视差与流动（v0.9）

微动对话框多了「镜」一栏：上传一张跟原图同比例的深度图（白=近、黑=远，例如 Depth Anything 生成），选镜头运动：推近、左右摇、上下摇、绕圈。每个像素按「自己的深度 − 焦点」移动，焦点那一层不动，近的跟镜头走、远的反方向，画面略放大避免露边；镜头在一个循环里转整数圈，导出仍是无缝循环。有深度图时可以只加镜头、不框区域。区域效果新增「流动」：框内波纹朝支点方向流，适合火焰、水、烟、旗帜。深度图存成素材，不算版本；agent 可用 `node cli.mjs motion depth SHOT_ID depth.png` 挂上去（没有镜头时自动设为慢推）。AiCut 自己不估深度。

### 静图微动（✦ 微动，v0.8）

不用写 prompt、不用模型，让静图小幅动起来。图片片段点「✦ 微动」，框出手、眼睛、头发或身体，选效果：颤抖、震动、呼吸、摆动（绕你点的支点，例如手腕）、漂浮、眨眼。强度、速度、边缘羽化即时预览，最多 8 个区域。只有框里会动，框外的变形量是 0，像素就是原图。每个效果在一个循环里转整数圈，「导出为新版本」逐帧编码（WebCodecs H.264，30fps，长度精确）成 MP4，作为这一段的新版本；原图仍是微动的来源，可以随时回来调。浏览器不支持 WebCodecs H.264 时改用实时录制。

### 时间线、音频与 agent（v0.7）

卡片上方是剪映式时间线：左边预览窗，上面视频轨（片段按顺序排开），下面 BGM／配音／音效音轨带波形。把音频文件或素材库里的声音拖到音轨上，拖动移动、拖边缘裁剪，音轨可静音、调 dB。切到「▭ 框选时间」在波形上拖出一段，写这段要怎么改。每个音频片段保留所有版本，检查面板可以对同一段做 A/B 试听。空格键播放。

卡片多了「台词」：每句选角色、写台词和语气。「角色声音」设定每个角色的声音来源、voice_id 和声音描述。台词会带进复制请求和 CLI 任务。

**交给 agent。** 每个「交给谁」下拉都会列出 herdr 里正在跑的 agent，以及「手动 · 复制指令」。音频任务有四种：处理一段音频（整段要求 + 框选时间段）、Shift 多选 2–6 段混音、把一段的台词配音到配音音轨、按描述生成 BGM。AiCut 只在 agent 的窗格里打一行指令；agent 用 `cli.mjs` 读任务，用自己的工具处理（本地分轨／ffmpeg，或 ElevenLabs MCP 等线上服务），再把结果导回成新版本或新片段。AiCut 本身不处理、不生成音频，也不保存任何 API key。每段的 Prompt 改写也可以推给 herdr agent。

**导出剪映。** 点「导出剪映」下载时间线清单，再运行 `python scripts/export_jianying.py 清单.json --drafts "剪映草稿文件夹"`（先 `pip install pyJianYingDraft`）生成剪映草稿：画面按区间排好、音轨带裁剪和音量、台词变成字幕放在平台安全区。重开剪映就能看到。

### 画面框选（▣ 框选）

片段画面下方点「▣ 框选」，暂停在要改的画面，按住鼠标拖出一个或多个框。每个框写一句要改什么；视频可以填段内开始／结束秒数（结束留空 = 到段尾）。框会显示在卡片画面上；以后再分段时，框会复制到时间范围重叠的每个小段。

复制请求和 CLI 任务会列出每个框的位置（如「右下」）和画面百分比坐标，并写明框外保持不变。「下载标注图」导出当前画面加红框编号；「下载 mask」导出同尺寸、框内白框外黑的 PNG，给支持局部重绘的工具用。两张图都在浏览器里生成。

框选只说明「改哪里」，不会直接改像素；纯文字模型仍可能改到框外，请检查结果。像素级「框外完全不变」的合成还没有做。

### 可选素材库扩展

顶部点「素材库扩展」开启右侧素材面板。导入／拖入本地音效、meme 图片／GIF、短视频，先试听或预览，再拖到某一段。也可以先点选片段，再点「添加到当前段」。填写段内第几秒，以及「要借用什么感觉」。

支持名称／标签搜索、收藏、来源／作者／授权记录和下载原素材，方便继续在剪映里完成制作。查看关联可调整说明与位置；解除关联只移除该段的链接。关闭扩展保留所有素材与关联，已有关联仍显示在片段下方。

片段重排时关联保留；再次分段时，范围内参考会移动到对应小段并换算相对时间。改变素材描述或参考说明会触发 CLI 结果冲突保护。

复制请求和 CLI 任务会包含参考名称、标签、位置、说明与来源；当前不会把素材文件直接附加给模型，也不保证 AI 能看图／听音。本版提供独立试听和感觉参考，不提供同步混音、画面叠加或合成导出。没有捆绑第三方音效／meme 包。详见 [扩展说明](extensions/asset-library/README.md)。

升级到 schema v4 前会生成 schema-v3-before-v4.sqlite 数据库快照；完整备份仍需 SQLite 和 media。请勿用旧版代码打开新数据。

### 本地 CLI 对接

现有 Claude Code／Codex 会话现在也能自己导入本地文件并分段，不用你点上传。服务运行后，CLI 可调用：

```sh
node cli.mjs projects
node cli.mjs import PROJECT_ID "path/to/source.mp4" --segments 5 --duration 30
```

示例表示一条已知 30 秒视频分 5 段。未知时长时，安装 ffprobe 并省略 --duration，由它读取；没有 ffprobe 又不知道时长时会明确失败，不猜分段。也支持自定时间点与再次细分，详见 CLI_BRIDGE.md。导入仅复制到本机；网页空闲时自动显示新片段，不丢弃未保存编辑。

先安装并用订阅账号登录 Claude Code 或 Codex CLI，再重启服务。每段底部选 CLI → **推送任务** → 等待完成 → **查看任务 / 结果** → **采用结果**。

推送包括该段 Prompt、修改要求、采用版本信息和原视频时间范围。默认一次执行一个任务，不直接附加视频文件。当前只产出文字修改稿，不自动改视频。采用时保留旧文字快照，原素材和备注不变。如果推送后你又改了该段，会阻止覆盖，需复制结果手动合并。

自动推送会启动新后台 CLI 进程，不是续接已有聊天。已有会话可选择「外部 CLI 领取」，通过 cli.mjs 读取、领取和回填任务。详见 [CLI_BRIDGE.md](CLI_BRIDGE.md)。失败或重启后不自动重试，避免重复消耗额度。

开发验证使用合成 CLI／执行器，不发送真实模型请求；本机两个 CLI 的安装及订阅登录类型已验证。真实模型输出及可用额度需实际推送后确认。
