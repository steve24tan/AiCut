新建项目

LOCAL EXTENSION

素材库

用看得见、听得到的参考，表达你想要的感觉。

先点一段，或直接拖到目标片段

可直接拖入本地文件。关闭扩展不删除素材或关联。本版仅试听与参考关联，不做混音导出。

素材信息

给这一段添加感觉参考

保存参考名称、位置和说明；CLI 会读取这些信息。本版不向模型附加素材文件，也不合成进视频。

视频分段

画面框选

暂停在要改的画面，按住鼠标拖出一个框，每个框写一句要改什么。复制请求和 CLI 任务会写明「只改框内，框外保持不变」。

微动

在静图上框出要动的地方，选效果、调强度和速度。只有框里会动，框外保持原图；加一张深度图还能让整张做 2.5D 视差镜头。导出为一段无缝循环视频，作为这一段的新版本。

生成 BGM

描述想要的音乐，交给 agent 生成（例如用 ElevenLabs 音乐），生成后会作为新片段放上所选 BGM 音轨。

链接下载

贴上视频页链接，用这台电脑的 yt-dlp 下载。视频成为新片段，音频存入素材库；来源链接和作者会记下来。下载别人的内容请自行确认版权和平台条款。

AI 音频任务

推送给 herdr agent 或手动复制指令的任务。agent 用 cli.mjs 领取、导回音频并回报结果；新音频不会覆盖旧版本。

角色声音

每个角色对应一个配音声音。voice_id 填 ElevenLabs 的声音 ID；还没选好可以先写声音描述。复制请求和 CLI 任务会带上这些信息。
